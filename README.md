# smartbancs-app
MVP para el reto técnico correspondiente a SmartBancs usando FastAPI, MariaBD y Docker.

# stack tecnológico
-Python
-FastAPI
-MariaDB
-SQLAlchemy
-Docker
-Docker Compose
-Pytest

# Objetivo
Construir un sistema financiero simple capaz de:
-Procesar transacciones financieras
-Gestionar operaciones concurrentes de manera segura.
-Integración asíncrona con un núcleo heredado Bancs simulado.
-Generación asíncrona de recomendaciones financieras.
-Monitoreo básico mediante logs y métricas.
-Demostración de la transformación de datos ETL.
